# 猎诈行动 Fraud Hunter —— 信号检测论（SDT）交互式实验网站

> 工程心理学 · 作业一：构建一个信号检测论交互式实验网站

## 一、场景说明

**你扮演市反诈中心的实时交易审核员。** 系统不断推送交易预警单，其中混有：

| 角色 | SDT 对应 | 现实含义 |
|---|---|---|
| **信号 Signal** | 诈骗交易 | 骗子诱导受害人转账，漏放 = 受害人资金损失 |
| **噪音 Noise** | 正常交易 | 普通用户真实转账，误拦 = 资金被冻结 + 投诉 |

每笔预警单附带 **AI 风险指数** 与 **可疑特征标签**，但 AI 并不完美：

- 正常单的可疑度强度 `s ~ N(0, 1)`
- 诈骗单的可疑度强度 `s ~ N(d′, 1)`

两个分布重叠，你必须在**限时内**做出「拦截 / 放行」的二择判断。

### 四种结果的实际含义

| | 实际：诈骗 | 实际：正常 |
|---|---|---|
| **拦截** | 击中 H：保住受害人资金 | 虚报 FA：误冻用户资金，引发投诉 |
| **放行** | 漏报 M：资金被转走，重大失误 | 正确排斥 CR：交易顺畅 |

默认先验概率 **P(S) = 0.30**（诈骗单少于正常单，更贴近现实；可在 0.10–0.50 间调节）。

**纯前端单文件，零依赖，无需联网、无需服务器：**

## 四、SDT 计算说明

```
d′ = z(P(Hit)) − z(P(FA))
c  = −[ z(P(Hit)) + z(P(FA)) ] / 2
β  = exp(d′ × c)
准确率 = (H + CR) / 总试次
```

为避免 P=0 或 P=1 时 z 值发散，采用 **log-linear 校正**（Macmillan & Creelman, 2005）：

```
P_corrected = (x + 0.5) / (n + 1)
```

z 分数由 Acklam 逆正态算法计算（前端实现，无需任何库）。

## 六、设计说明

- **场景**：本作主题为**反诈中心交易审核**。
- **风格**：本作为**深色赛博 SOC 大屏风**，且所有图表（双分布、ROC、历史柱状图）均为**手写 Canvas 绘制**，离线双击即可运行。
- **机制细节**：刺激强度 `s` 驱动渲染（风险指数 = 50 + 13s，高亮标签数随 s 递增），两类试次共用同一渲染管线，保证理想观察者的 d′ 恰等于系统设定值。
