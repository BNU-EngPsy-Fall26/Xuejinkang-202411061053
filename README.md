# 猎诈行动 Fraud Hunter —— 信号检测论（SDT）交互式实验网站

> 基于信号检测论的纯前端心理物理学交互实验。本项目通过模拟“市反诈中心实时交易审核”场景，让参与者在限时压力下进行二择判断，直观体验并计算敏感性（d′）与判断标准（c）。

## 一、项目简介

本项目是一个零依赖、纯前端的交互式网页实验系统。它将经典的信号检测论范式与贴近现实的“反诈交易审核”场景相结合。参与者需要在高度逼真的安全运营中心（SOC）界面中，处理不断推来的交易预警单，并在有限时间内决定“拦截”或“放行”。实验结束后，系统会自动统计混淆矩阵，计算并可视化 SDT 核心指标。

## 二、场景与参数说明

**你扮演市反诈中心的实时交易审核员。** 系统不断推送交易预警单，其中混有：

| 角色 | SDT 对应 | 现实含义 |
|---|---|---|
| **信号 Signal** | 诈骗交易 | 骗子诱导受害人转账，漏放 = 受害人资金损失 |
| **噪音 Noise** | 正常交易 | 普通用户真实转账，误拦 = 资金被冻结 + 投诉 |

每笔预警单附带 **AI 风险指数** 与 **可疑特征标签**，但 AI 并不完美：
- 正常单的可疑度强度 `s ~ N(0, 1)`
- 诈骗单的可疑度强度 `s ~ N(d′, 1)`

两个分布重叠，参与者必须在**限时内**做出「拦截 / 放行」的二择判断。

### 四种结果的实际含义

| | 实际：诈骗 | 实际：正常 |
|---|---|---|
| **拦截** | 击中 H：保住受害人资金 | 虚警 FA：误冻用户资金，引发投诉 |
| **放行** | 漏报 M：资金被转走，重大失误 | 正确拒斥 CR：交易顺畅 |

默认先验概率 **P(S) = 0.30**（诈骗单少于正常单，更贴近现实；可在 0.10–0.50 间调节）。

## 四、核心功能

### 1. 参数配置系统
- **难度调节**：提供 d′（0.5 - 3.5）滑块，控制信号与噪音分布的重叠程度。
- **先验概率调节**：提供 P(S)（0.10 - 0.50）滑块，控制诈骗单在总预警单中的比例。
- **试次数量**：可选择 20 / 50 / 100 试次，满足不同时长的实验需求。
- **刺激呈现限时**：可选择 2秒 / 3秒 / 5秒，超时自动进入判断阶段。

### 2. 交互式检测游戏
- **逐试次判断**：系统随机生成诈骗或正常交易预警单，附带由可疑度强度 `s` 驱动的 AI 风险指数和可疑标签。
- **限时决策**：判断阶段限时 5 秒，超时未按键默认视为“放行”。
- **快捷操作**：支持键盘快捷键 `F`（拦截）和 `J`（放行），提升操作流畅度。
- **即时反馈**：每次判断后立即显示击中、漏报、虚警或正确拒斥的反馈，并附带现实场景的后果描述。

### 3. SDT 指标计算与展示
- 自动生成混淆矩阵（H / M / FA / CR）。
- 计算并展示：击中率 P(Hit)、虚警率 P(FA)、敏感性 d′、判断标准 c、似然比 β、准确率 Accuracy。
- 提供个性化“值班点评”，根据 d′ 和 c 的值解释参与者的表现倾向（保守或宽松）。

### 4. 数据可视化与历史记录
- **概念可视化实验室**：通过拖动 d′ 和 c 滑块，实时联动双分布图（四块面积着色）与 ROC 曲线，并显示 AUC。
- **历史战绩存储**：利用 `localStorage` 自动保存每一局的数据。
- **排行榜与对比**：提供按 d′ 排序的历史排行榜，以及各局 d′ 柱状对比图。
- **ROC 散点标注**：历史成绩会自动标注在 ROC 曲线上，便于观察多局数据的分布。

## 五、SDT 计算说明

本项目采用以下公式计算 SDT 核心指标：
```
d′ = z(P(Hit)) − z(P(FA))
c  = −[ z(P(Hit)) + z(P(FA)) ] / 2
β  = exp(d′ × c)
准确率 = (H + CR) / 总试次
```

为避免 P=0 或 P=1 时 z 值发散，采用 **log-linear 校正**（Macmillan & Creelman, 2005）：

```
P_corrected = (x + 0.5) / (n + 1)
```

z 分数由 Acklam 逆正态算法计算（前端实现，无需任何库）。

## 七、设计说明与实现细节

### 1. 场景与原创性设计
本项目选择了**“反诈中心交易审核”**这一具有高度现实意义和紧迫感的场景。通过模拟真实的交易预警单界面，增强了参与者的代入感，使心理物理学实验不再枯燥，同时具备一定的社会现实价值。

### 2. 视觉与界面风格
本项目采用了**深色赛博 SOC（安全运营中心）大屏风格**，以霓虹青为主色，辅以扫描线、网格底纹和 LIVE 状态灯。这种高对比度、低亮度的设计不仅美观，还能有效降低长时间实验带来的视觉疲劳，符合监控席位的真实工作环境。

### 3. 技术架构与零依赖
- **单文件架构**：所有 HTML、CSS 和 JavaScript 均封装在一个 `index.html` 中，彻底避免了路径错误和依赖加载失败的问题，真正实现“双击即运行”。
- **手写 Canvas 图表**：与使用第三方库不同，本项目中的双分布图、ROC 曲线和历史柱状图均为**手写 Canvas 绘制**。这不仅实现了零外部依赖，还极大地提升了图表联动的响应速度，展示了底层图形编程能力。

### 4. 心理物理学机制细节
为了确保实验的严谨性，本项目在机制设计上做了特殊处理：
- **刺激强度 `s` 驱动渲染**：每试次生成一个“可疑度强度” `s`（正常单 `s ~ N(0,1)`，诈骗单 `s ~ N(d′,1)`）。渲染函数对两类试次完全相同，AI 风险指数（`score = 50 + 13s`）和高亮可疑标签数（`nHot = clamp(1.2 + s * 1.1, 0, 5)`）均为 `s` 的确定函数。
- **理想观察者模型**：这种设计保证了两类试次共用同一渲染管线，使得理想观察者的经验 d′ 恰好等于系统设定的 d′ 值，确保了实验数据的内部效度。
- **装饰性随机**：交易金额、账户、附言等元素均为纯装饰性随机（两类试次同分布），避免参与者利用无关特征进行判断。
- **限时压力机制**：引入了刺激呈现限时和判断限时（超时默认放行），更贴近真实监控场景的决策压力，提升了实验的生态效度。
