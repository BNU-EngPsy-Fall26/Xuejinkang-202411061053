任务简报

你是市反诈中心的一名实时交易审核员，系统会不断向你推送交易预警单， 里面混着诈骗交易（信号）和正常交易（噪音）。 每笔预警单都附有 AI 风险指数和可疑特征标签，但 AI 并不完美， 诈骗单的可疑度服从 N(d′, 1)，正常单服从 N(0, 1)， 两个分布相互重叠。你要做的，是在限时之内凭这些不完整的信息做出判断， 这笔交易该拦截，还是该放行。

信号与噪音定义

信号 = 诈骗交易骗子冒充客服或公检法，诱导受害人把钱转出去，漏放一笔，受害人可能损失全部积蓄。
噪音 = 正常交易普通用户的真实转账，误拦一笔，用户的资金会被冻结，投诉也会跟着来。

先验概率 P(S) 指诈骗交易在所有预警单中的占比，现实里诈骗单远少于正常单，所以默认取 0.30。 信号越稀有，"一律放行"的准确率反而越高，这正是准确率指标会失灵、我们需要 SDT 的原因。

四种判断结果的实际含义

击中 H · 成功拦截实际是诈骗，你选择了拦截，受害人的资金保住了。
漏报 M · 漏放诈骗实际是诈骗，你选择了放行，受害人的钱被转走了，这是最严重的失误。
虚警 FA · 错误拦截实际是正常交易，你却选择了拦截，用户资金被误冻，投诉马上就到。
正确拒斥 CR · 正确放行实际是正常交易，你选择了放行，一切顺利。

实验参数

判断阶段同样限时 5 秒，超时没按键就当作放行，因为在真实的监控席上，不处置就等于放行。 快捷键 F 表示拦截（有诈），J 表示放行（正常）。

计算说明：d′ = z(P(Hit)) − z(P(FA))，c = −[z(P(Hit)) + z(P(FA))] / 2，β = exp(d′ × c)。 为了避免出现 0 或 1 的极端比率让 z 值发散，这里采用 log-linear 校正，即 P = (x + 0.5) / (n + 1)（Macmillan & Creelman, 2005）。 c 大于 0 说明你偏保守，宁可漏报也不愿误拦，c 小于 0 说明你偏宽松，宁可误拦也不愿漏报。

想一想，为什么准确率会骗人？

本局 P(S) = 0.30，也就是说，如果有人的策略是全部放行， 他的准确率立刻就有 70%，可他的 P(Hit) 是 0，诈骗一笔都没拦住。 准确率这个指标把你的能力（d′）和你的标准（c）混在了一起，SDT 要做的，正是把这两件事分开来看。

ROC 曲线

同一条 ROC 曲线代表同一个 d′ 下，不同判断标准 c 能得到的所有工作点，青点是当前滑块所在的位置， 紫色点是你历史各局的真实成绩，对角线则是随机猜测的水平（d′=0）。 曲线越贴近左上角，说明敏感性越高。
